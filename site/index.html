GPUFLO

A light, fast terminal dashboard for AMD GPUs on Linux.

Install
$ cargo install gpuflo --locked
$ curl -fsSL https://raw.githubusercontent.com/mikeroySoft/gpuflo/main/install.sh | sh

No ROCm. No root. No daemon. Just Linux and the in-kernel amdgpu driver. Checksums on every release.

Three questions, one second

GPUFlo reads Linux amdgpu kernel interfaces directly — sysfs, hwmon, versioned gpu_metrics, DRM fdinfo — and answers immediately:

What is the selected physical GPU doing?
How much of its applicable memory pool is occupied?
Is a source-backed fault, throttle, limit, pressure, sleep, permission, or telemetry problem active?

Light, fast, accurate

Light

One small static binary, strictly read-only. No ROCm userspace, no root, no daemon, no database, no network. Optional sources only ever add information.

Fast

First reading in under a second. Telemetry samples on a dedicated 250 ms kernel lane that rendering, overlays, and process scans can never block.

Accurate

Socket-scoped temperature and power kept separate from partition-scoped activity, memory, and clocks. Missing telemetry is an explicit state — stale, asleep, permission_denied — never a made-up zero.

Extensible & embeddable

Stream --json / --json-stream NDJSON into scripts, or embed the semver-supported Rust Monitor API — the same canonical model that drives the TUI.

Responsive views

Full mode, compact, mini, and one-line tiny views auto-select by terminal size. Works as a floating desktop widget.

Process attribution

Press p: PID, name, GPU/XCP, VRAM, GTT, KFD memory, and container identity — permission failures shown explicitly rather than hidden.

Extend it

The same canonical telemetry model drives the TUI, a stable JSON/NDJSON contract for scripts and pipelines, and a semver-supported Rust library for embedding.

Stream NDJSON into anything

# one snapshot, or a continuous stream
gpuflo --json
gpuflo --json-stream | jq .gpus[0].activity

# never null, NaN, or fake zero:
{ "value": 97.0,
  "observed_at": "2026-08-21T23:45:12Z" }
{ "state": "permission_denied" }

Embed the Monitor in Rust

use gpuflo::{Monitor, MonitorEvent, MonitorOptions};

let monitor = Monitor::start(MonitorOptions::new())?;
match monitor.receive()? {
    MonitorEvent::Snapshot(s) =>
        println!("{} GPU(s)", s.gpus.len()),
    MonitorEvent::Fatal(e) => return Err(e.into()),
    _ => {}
}
