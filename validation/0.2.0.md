## Changes since 0.1.1

- Add `gpus[].platform` (`id`, `memory_pool`) to `--json` and every
  `--json-stream` record, plus public `Platform`, `PlatformId`, and
  `PhysicalGpu::platform` in the Rust library. Platform classifier credit:
  Matt Elliott (#3); JSON/NDJSON contract tests and docs: #10.
- Add `--json-stream --for <DURATION>` for bounded captures (#16).
- Add source-reported throttle episodes in `daily.json` (#15).
- Add the `l` key to toggle the dashboard logo; `→` selects the next GPU and
  `←` or `h` selects the previous GPU (#8).
- Document the `schema_version` compatibility policy in the README (#14).
- Mark `Snapshot`, `PhysicalGpu`, `Partition`, `Memory`, `Health`,
  `Temperature`, `Power`, and `Platform` as `#[non_exhaustive]` (#20).
- Refuse daily-summary records larger than the 64 KiB load budget, preserving
  the previous file (#15).
- Route Strix Halo GTT accounting through the platform classifier, with
  unchanged results (#3).
- Project tooling and site work not shipped in the crate or binary: AI-factory
  tooling and factory dashboard themes (#4, #5, #6, #17); project website
  pages; CI and release runners pinned to `ubuntu-24.04` (#18); README
  daily-summary disclosure (#19).
